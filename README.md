# 🌿 Perfumería ARIA — Plataforma E-commerce de Perfumes Originales

**Perfumería ARIA** es un proyecto académico y empresarial que desarrolla el diseño, documentación y arquitectura de una **tienda virtual para la venta de perfumes 100% originales en Colombia**, con un enfoque en **experiencia digital premium**, asesoría personalizada y eficiencia logística.

Este repositorio contiene:
- El estudio de prefactibilidad completo (viabilidad de negocio)
- El anexo financiero con proyecciones y costos
- El código fuente de una página web funcional (HTML, CSS y JavaScript)
- Logo e imágenes del proyecto

---

## 🎯 Objetivo del proyecto

Crear una alternativa digital accesible y confiable para adquirir perfumes originales en Colombia, eliminando barreras físicas y ofreciendo una experiencia diferenciada basada en:
- Autenticidad del producto
- Personalización mediante asesores y guías digitales
- Empaque premium y cadena logística optimizada
- Seguridad de compra y seguimiento en tiempo real

## 🧠 Resumen del Estudio (docs/ARIA_FINAL.pdf)

El documento incluye un análisis completo sobre:

| Componente | Contenido |
|-----------|-----------|
| Estudio de mercado | Target: Hombres y mujeres 18-45 años, estratos 3-6, consumidores digitales. Mercado potencial estimado: 4,8M personas. |
| Demanda potencial | Posible captación inicial: 390.000 perfumes/año. Intención de compra: 81%. |
| Operación – logística | Capacidad: 45.500 pedidos mensuales. Ubicación recomendada: Medellín (San Diego). Flujo: Pedido → Bodega → Alistamiento → Empaque → Envío. |
| Organización empresarial | Cargos: Gerente, Contador, TI, Bodega, Operarios, Asesores Online. |
| Estudio financiero | Inversión inicial proyectada: $70,7M COP. Inversión total a 5 años: $84,7M COP. Indicadores financieros: VAN, TIR y análisis de sensibilidad. |

> Conclusión: ARIA es viable y rentable como modelo de negocio de comercio electrónico.

## 🚀 Cómo ejecutar o visualizar la web

### 🔹 Opción 1 — Local
1. Descarga el repositorio
2. Abre `/src/index.html` en un navegador

### 🔹 Opción 2 — GitHub Pages 
Después de subir el repositorio:
1. Ir a **Settings → Pages**
2. Seleccionar branch: `main`
3. Seleccionar carpeta `/src`
4. Guardar — GitHub generará una URL pública
